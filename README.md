# волнотропы — сайт

Статический сайт без сборки и зависимостей. Каждая страница — один
самодостаточный HTML-файл: оформление, знак и фавиконка лежат внутри него,
поэтому любую папку можно залить отдельно, хоть на субдомен.

```
volnotropy/
├── index.html          главная: что это, проекты, контакты
├── photos/             картинки для плиток на главной
├── vt01/               страница проекта «VT01 и дистро»
│   ├── index.html
│   └── photos/
├── idm-chess/          страница ивента «IDM Шахматы»
│   ├── index.html
│   └── photos/
├── listening/          страница «Листенинг-сессии»
│   ├── index.html
│   └── photos/
├── synthtusa/          подсайт фестиваля «Синтитуса» (своё оформление)
│   ├── index.html      плакат, что это, опен-колл, билеты, организаторы
│   ├── open-call/      подробности опен-колла и анкета
│   ├── photos/         фотографии организаторов
│   ├── og.png          картинка для ссылок в телеграме и соцсетях
│   ├── synthtusa.ics   файл «добавить в календарь»
│   └── logo.png        ← положите сюда логотип Синтитусы
├── logo.png            исходник знака (белый на прозрачном)
├── archive/
│   └── materials.html  прошлая версия сайта со всеми текстами
└── tools/
    └── sync-style.py   разложить оформление из index.html по страницам
```

## Фотографии

В каждой папке `photos/` лежит текстовый файл с нужными именами файлов.
Положили `vt01-1.jpg` — фотография появилась, не положили — её просто нет.
Если на странице не нашлось ни одной, вместо галереи будет строчка
«фотографии скоро». Ничего в коде править не нужно.

Чтобы добавить фотографий больше, чем заложено, допишите строку в блок
`<div class="gallery">` соответствующей страницы:

```html
<img src="photos/chess-5.jpg" alt="Турнир" loading="lazy" width="1200" height="900">
```

## Новый ивент

1. Скопируйте папку `idm-chess` и назовите её по ивенту: `cp -r idm-chess drone-day-2027`
2. Почистите `photos/` и откройте `index.html` — поправьте заголовок, подзаголовок,
   блок с данными (когда / где / вход), текст, тайм-тейбл и `<title>` в шапке файла.
3. Добавьте плитку на главную: скопируйте в `index.html` один блок `<a class="tile">`
   внутри `<div class="tiles">` и поменяйте ссылку, рубрику, название и описание.

## Публикация

Весь сайт — статика, подойдёт любой хостинг.

**Целиком на volnotropy.ru.** Залейте папку в корень. Страницы откроются по
адресам `volnotropy.ru/vt01/`, `volnotropy.ru/idm-chess/` и так далее.

**Ивент на субдомене** (`synthtusa.volnotropy.ru`, `idmchess.volnotropy.ru`):

1. В DNS добавьте A- или CNAME-запись для поддомена и укажите на тот же хостинг.
2. Залейте содержимое папки (`synthtusa`, `idm-chess`…) в корень субдомена.
3. Страницы волнотропов (`idm-chess`, `vt01`, `listening`) ссылаются на главную
   относительным путём — поменяйте две ссылки `../index.html` на
   `https://volnotropy.ru/`: в шапке у `class="brand"` и в строчке
   «← волнотропы» у `class="back"`. Папку `synthtusa` править не нужно:
   она уже ссылается на главную абсолютным адресом.
4. Для `synthtusa` допишите в `<meta property="og:image">` полный адрес
   картинки (`https://synthtusa.volnotropy.ru/og.png`) — телеграм и часть
   соцсетей не понимают относительные пути в og:image.

На GitHub Pages и Netlify субдомен настраивается в их панели, DNS — у регистратора.

## Синтитуса

Подсайт в папке `synthtusa/` живёт по своим правилам: белый фон, голубой
акцент волнотропов, Oswald для крупного и IBM Plex Mono для всего остального.
Страниц две — главная и `open-call/` с условиями и анкетой.
`tools/sync-style.py` эту папку не трогает: оформление здесь своё.

**Билеты.** Ссылка задаётся одной строкой в начале `<script>` главной:

```js
const TICKETS_URL = '';     // сюда адрес страницы с билетами
```

Пока строка пустая, обе кнопки честно говорят «билеты скоро» и ведут в канал.
Вписали адрес — обе становятся «Купить билеты».

**Фотографии организаторов.** `synthtusa/photos/daniil.jpg` и `svyat.jpg`,
квадратные. Пока файлов нет, на их месте серые заглушки с подписью «фото».

**Логотип.** В шапке он во всю ширину экрана и анимированный:

- `logo.mp4` — анимация, 849 КБ. Пережата из `logo.gif` (19 МБ): фон подменён
  на белый, лёгкое шумоподавление, 12.5 кадра в секунду, 1100 px по ширине.
  Проигрывание «пинг-понг»: кадры идут туда и обратно (98 кадров, 7.8 с),
  поэтому петля стыкуется без скачка — в исходной гифке переход от последнего
  кадра к первому заметен. Вставлена как `<video autoplay muted loop playsinline>`:
  ведёт себя как гифка, но весит в 22 раза меньше.

  В файле есть **беззвучная аудиодорожка** — без неё Safari проигрывает ролик
  один раз и останавливается, это его давняя особенность. На странице элемент
  всё равно стоит с `muted`, так что ничего не звучит. Плюс в скрипте есть
  подстраховка: на событие «кончилось» ролик перематывается в начало, и раз
  в две секунды сторож проверяет, не завис ли он у конца.
- `logo.png` — тот же знак статикой (212 КБ). Он и постер видео, и запасной
  вариант, и картинка для афиши `og.png`.
- `logo.gif` — исходник. Страница его **не** использует, на хостинг можно
  не заливать.

Если ни видео, ни картинка не нашлись — в шапке остаётся надпись «Синтитуса»
тем же кеглем. При системной настройке «уменьшить движение» анимация
не запускается, показывается статичный кадр.

**Как заменить знак.** Положите новый `logo.gif` и пересоберите видео
(нужен ffmpeg; скрипт разбора фона — в истории переписки):

```bash
# пинг-понг прямо средствами ffmpeg: кадры туда, потом обратно
ffmpeg -i logo.gif -filter_complex \
  "[0:v]hqdn3d=3:2:4:4,scale=1100:-2,fps=12.5,split[a][b];[b]reverse,trim=start_frame=1[r];[a][r]concat=n=2:v=1" \
  -c:v libx264 -preset slow -crf 31 -pix_fmt yuv420p -movflags +faststart -an logo.mp4
```

**Заявки с сайта.** Форма отправляет заявку POST-запросом на адрес, который
вы впишете в начале `<script>`:

```js
const FORM_ENDPOINT = '';   // сюда адрес приёмника
const WEB3FORMS_KEY = '';   // только если выбрали Web3Forms
```

Подойдёт любой сервис, принимающий JSON: Web3Forms (бесплатно, ключ приходит
на почту за минуту), Formspree, Getform — или свой обработчик на малине.
Пока строка пустая, кнопка собирает заявку в письмо и открывает почтовый
клиент: сайт рабочий, просто без автоматики.

**Картинка для ссылок.** `og.png` собирается скриптом, который лежит в истории
переписки; если поменяются дата или место — перерисуйте её, иначе в телеграме
будет висеть старая афиша. Размер 1200×630.

**Календарь.** `synthtusa.ics` — файл с датой, его отдаёт ссылка «в календарь»
в подвале. Поменяли дату на странице — поменяйте и здесь (`DTSTART`/`DTEND`).

## Оформление

- Шрифты: Golos Text (текст) и JetBrains Mono (даты, рубрики, служебные подписи).
- Цвета — CSS-переменные в начале каждого файла (`:root`): белый, холодный серый,
  голубой. Акцент — `--accent`, тёмная тема описана там же ниже.
- Никаких скруглений, теней и таблиц: данные подаются подзаголовком и значением
  под ним, разделители — волосяные линейки в 1 px.
- Тело сайта прижато к левому краю; отступ слева — переменная `--pad`
  (2.5rem на десктопе, 1.25rem на телефоне).
- Поправили оформление в `index.html` — выполните `python3 tools/sync-style.py`,
  чтобы те же стили разъехались по остальным страницам.

## Логотип

`logo.png` — исходник (белый знак на прозрачном фоне, 1024×1024). В страницы он
зашит как CSS-переменная `--logo`: знак работает маской, а цвет берётся из темы.
Фавиконка сделана из него же. Чтобы заменить знак, положите новый `logo.png`
и пересоберите переменную во всех файлах:

```bash
python3 -c "
from PIL import Image; import base64, io, re, glob
a = Image.open('logo.png').convert('RGBA').getchannel('A')
a = a.crop(a.getbbox()); w, h = a.size
m = a.resize((256, round(h*256/w))).point(lambda v: 0 if v<40 else (128 if v<170 else 255))
b = io.BytesIO(); Image.merge('LA', (Image.new('L', m.size, 255), m)).save(b, 'PNG', optimize=True)
url = 'data:image/png;base64,' + base64.b64encode(b.getvalue()).decode()
for f in ['index.html'] + glob.glob('*/index.html'):
    if f.startswith('archive'): continue
    s = open(f).read()
    open(f,'w').write(re.sub(r'--logo:url\(\"[^\"]*\"\);', '--logo:url(\"' + url + '\");', s))
"
```

## Архив

`archive/materials.html` — прошлая версия сайта: лента со всеми написанными
материалами (статья про Reunion, гид по дроуну, репортажи, анонсы). Файл
самодостаточный, открывается двойным кликом. На сайт не ссылается и не
публикуется — лежит, чтобы тексты не потерялись.
