# Как залить сайт на GitHub Pages

Сайт — статика, поэтому Pages подходит целиком: ни сборки, ни серверного кода.
Внешняя зависимость одна — шрифты Google Fonts.

Аккаунт: `Cirocular-Vlasenko-Daniil`. Репозиторий `Cirocular-Vlasenko-Daniil.github.io`
уже занят зином, поэтому волнотропы заливаются **отдельным репозиторием проекта** —
на кастомные домены это никак не влияет.

---

## 1. Основной сайт → volnotropy.ru

**Репозиторий.** Создайте на GitHub пустой репозиторий, например `volnotropy`
(публичный — для бесплатных Pages на личном аккаунте это обязательно).
Затем из папки сайта:

```bash
git remote add origin https://github.com/Cirocular-Vlasenko-Daniil/volnotropy.git
git push -u origin main
```

**Включить Pages.** Settings → Pages → Build and deployment → Source: *Deploy from
a branch*, ветка `main`, папка `/ (root)`. Через минуту сайт поднимется по адресу
`https://cirocular-vlasenko-daniil.github.io/volnotropy/` — на этом этапе всё уже
работает и можно проверить ссылки.

**Домен.** Settings → Pages → Custom domain → `volnotropy.ru` → Save.
GitHub сам создаст в репозитории файл `CNAME` — руками его добавлять не нужно.

**DNS у регистратора** (для `volnotropy.ru`):

| Тип | Имя | Значение |
|-----|-----|----------|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | cirocular-vlasenko-daniil.github.io |

Записи подхватываются от нескольких минут до пары часов. Когда GitHub увидит
домен, в Settings → Pages станет доступна галочка **Enforce HTTPS** — поставьте,
сертификат бесплатный.

После подключения домена поправьте адрес картинки для ссылок, если решите
не держать Синтитусу на субдомене: в `synthtusa/index.html` и
`synthtusa/open-call/index.html` строка `og:image` уже указывает на
`https://volnotropy.ru/synthtusa/og.png`.

---

## 2. Синтитуса → synthtusa.volnotropy.ru

GitHub Pages даёт **один домен на репозиторий**, поэтому субдомен — это второй
репозиторий. Готовую папку для него собирает скрипт:

```bash
python3 tools/make-subdomain.py synthtusa synthtusa.volnotropy.ru
```

Он создаст рядом с проектом папку `volnotropy-synthtusa`: скопирует файлы
(без исходной гифки), подменит ссылки на главную на `https://volnotropy.ru/`
и пропишет `og:image` под новый домен.

Дальше — обычная процедура: пустой репозиторий (например `synthtusa`), заливаете
содержимое папки, Settings → Pages → ветка `main`, Custom domain →
`synthtusa.volnotropy.ru`.

**DNS:**

| Тип | Имя | Значение |
|-----|-----|----------|
| CNAME | synthtusa | cirocular-vlasenko-daniil.github.io |

Пересобирать папку нужно после каждой правки страницы — скрипт запускается
заново и перезаписывает её целиком.

**Если субдомен не нужен** — ничего из этого раздела делать не надо: фестиваль
и так открывается по адресу `volnotropy.ru/synthtusa/`.

---

## 3. Что уже подготовлено в репозитории

- `.nojekyll` — Pages не будет прогонять сайт через Jekyll.
- `.gitignore` — из репозитория исключён `synthtusa/logo.gif` (18 МБ, страницей
  не используется: анимация идёт из `logo.mp4`). Если захотите хранить исходник
  в репозитории — `git add -f synthtusa/logo.gif`.
- `404.html` — страница «такой страницы нет» в оформлении сайта. Pages показывает
  её автоматически.
- Все внутренние ссылки относительные, поэтому сайт одинаково работает и по
  адресу `…github.io/volnotropy/`, и на своём домене.

## 4. Обновление сайта

```bash
git add -A
git commit -m "что изменилось"
git push
```

Pages пересобирает сайт сам, обычно меньше чем за минуту. Если поменяли
Синтитусу и она живёт на субдомене — не забудьте перезапустить
`tools/make-subdomain.py` и залить второй репозиторий.

## 5. Лимиты, в которые мы укладываемся

Сайт весит 2.4 МБ (из них 0.9 МБ — анимация логотипа). У Pages ограничения:
1 ГБ на сайт, 100 МБ на файл, около 100 ГБ трафика в месяц и 10 сборок в час.
